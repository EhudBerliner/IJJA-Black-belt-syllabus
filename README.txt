=====================================================
 סילבוס חגורה שחורה - IJJA
 מדריך להעלאת האפליקציה והפעלתה ב-GitHub Pages
=====================================================

כדי להפעיל את האפליקציה באופן עצמאי בחינם דרך GitHub, עקבו אחר הצעדים הבאים:

1. הרשמה / התחברות:
   - היכנסו לאתר https://github.com
   - הירשמו למועדון/התחברו לחשבון שלכם.

2. יצירת מאגר חדש (Repository):
   - לחצו על כפתור New (או על ה-"+" בפינה העליונה ולחצו על "New repository").
   - בשם המאגר (Repository name), הקלידו למשל: ijja-syllabus
   - ודאו שהמאגר מוגדר כ-Public.
   - לחצו על Create repository בתחתית הדף.

3. העלאת הקבצים:
   - בדף שנפתח, לחצו על הקישור "uploading an existing file".
   - גררו אל המסך את כל הקבצים שחילצתם מקובץ ה-ZIP הזה (כולל index.html, sw.js, manifest.json, Black_belt_syllabus_IJJA.csv, ו-README.txt).
   - לחצו על כפתור Commit changes הירוק בתחתית הדף.

4. הפעלת האתר (GitHub Pages):
   - בלשונית העליונה של המאגר, היכנסו ל-Settings.
   - בתפריט הצדדי (משמאל), לחצו על Pages.
   - תחת Build and deployment -> Branch, שנו מ-None ל-main (או master).
   - לחצו על Save.
